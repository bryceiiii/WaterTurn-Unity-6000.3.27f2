# 像素素材清单 · 萌版

面向 itch.io 的选材清单，按工程里真实存在的素材缺口整理。**本版按「萌系」重排**，硬朗地牢风退到备选。

风格基准（从现有素材反推）：`Fish/swim_*.png` 是暖橙、粗深描边、大眼、圆润的小鱼；`Water/wood.png` 是柔和的暖木色。所以「萌」= **粗描边 + 暖色/粉彩 + 圆角 + 大眼睛**，不是石砖铁栅那种硬边。

规格基准：`Assets/Editor/PixelArtImport.cs` 统一 16 PPU / Point / 无压缩；关卡格子 `LevelBoard.cell = 100`（UGUI 像素）；序章洞穴 `HubGame.Cell = 28`。

## 一、当前缺口

| 槽位 | 现在怎么来的 | 萌版要什么 |
|---|---|---|
| 木箱 `crate` | `Water/wood.png`（29×32） | 圆角木箱、浅木色、有笑脸也行 |
| 栅栏 `fence` | 代码程序化绘制 | 圆头木栅栏，不要铁条 |
| 闸门 `gate` | 代码程序化绘制 | 木质闸门或贝壳闸门，关/开两态 |
| 感应格 `sensor` | 代码程序化绘制 | 发光的圆形贝壳/水纹地毯，未触发/已触发 |
| 收集物 `pearl` | 代码程序化绘制 | **空螺壳**（剧情简案 B）→ 海螺/扇贝，带一点高光 |
| 海草 / 潮心 `portal` | 代码程序化绘制 | 摆动海草 + 圆滚滚的发光核心 |
| 石门 `stoneDoor` | 代码程序化绘制 | 圆拱木门或珊瑚门，关/开两态 |
| UI 按钮 | 只有 `Art/UI/rounded.png` | 粉彩圆角面板 + 圆润图标 |
| 气泡 · 浮尘 | 无 | 可选，洞穴氛围 |

> 关卡里的 `gate` / `sensor` / `pearl` / `crate` 都是 Prefab 上的 `Image`，要的是**按对象包围盒裁好的单张 PNG**，不是 tileset 里的一格。

## 四、必须知道的坑：萌系包里没有「机关」

萌系素材几乎都是农场 / 生活 / RPG 风格，**压力板、闸门、栅栏这类解谜机关基本不存在**。你只有三条路：

1. **从 Ninja Adventure 里拆**：它有关闭/打开的门和开关，材质偏木质，改造一下能当闸门。
2. **从 Sprout Lands 里拼**：用木栅栏横向重复拼出「通水不通鱼」的一格，用木板拼闸门——规则简单，视觉上反而更像萌系该有的样子。
3. **自己改**：CC0 和 $3.99 的包都允许改色改形。用 Aseprite 在现成木箱上开两道栅栏缝，比找包快。

我的建议是 **2 + 3**：栅栏和闸门本来就该长得像「木工活」，萌系的圆头木条正合适；而压力板用 Cozy Fishing 的扇贝壳 + 一层青色发光，就是现成的「潮汐感应格」。

## 六、不建议

- **32×32 以上、RPG Maker MV 风**：缩到 16 会糊。
- **写实地牢 / 石砖铁栅**：和暖橙小鱼是两种语言。
- **纯横版平台 tileset**：视角不符，只能拆道具。
- **刻意混三个作者的描边宽度**：萌系最怕描边不统一，一眼看出是拼的。**选一个主包当基准（我建议 shubibubi），其余只取局部。**

## 七、接入注意（比选包更重要）

1. **像素对齐是真问题**：`cell = 100`、`Cell = 28`，16px 素材被缩放 **6.25× / 1.75×**，都是非整数倍，屏幕上像素会忽大忽小。建议 cell 改 **96 / 128**，Hub `Cell` 改 **32 / 48**。
2. 新素材放 `Assets/Resources/Art/` 下**新建子目录**（`Props/`、`Shell/`、`UI/Cozy/`），不要丢进 `Cave/`。
3. 导入沿用 `Assets/Editor/PixelArtImport.cs`：Point、无压缩、16 PPU、Center 轴心；单个物件按包围盒裁边，避免 gizmo 偏移。
4. 关卡里的 `crate / gate / sensor / pearl` 换图**不用改代码**，只换 Prefab 上的 Sprite 引用（`LevelBoard` 字段已就位）。
5. **许可务必记清**：shubibubi 和 Cup Nooble 的免费版**只允许非商用**，公开发布前必须买 $3.99 版；Ninja Adventure 和 Ishtar 是 CC0，随便用。发布前统一写入 `Assets/Resources/Art/Cave/CREDITS.md`。
6. **先做调色板收敛**：把各包统一到暖橙 + 青蓝双主色（约 24–32 色），再进 Prefab。

## 八、背景 / 地面素材（俯视可平铺）

### 先说结论：名字里带 Background 的基本都不能用

逐个核对过页面标签，itch 上「cave background」这个搜索词返回的头部结果几乎全是**横版视差图**，放进俯视格子棋盘必错：

- **Ludenc – Cave Background and Tileset**（32×32）标签写的是 `Side Scroller`。https://ludenc.itch.io/cave-background-and-tileset
- **Lil Cthulhu – Pixel Art Cave Background**（640×250，多图层视差）。https://lil-cthulhu.itch.io/pixel-art-cave-background
- **SlashDash – Cave background pixel art**（1280×720 单张，CC-BY 4.0）。https://gamesmashdash.itch.io/cave-background-pixel-art
- **Marco Brito – 10 Pixel Art RPG Backgrounds**（1280×720，含 cave）。https://marcomyly.itch.io/free-demo-10-pixel-art-rpg-backgrounds-16-bit-snes-inspired-1280720-png

本项目要的不是「一张画」，是**一张可平铺的俯视地面纹理**。证据在代码里：

- Hub：`HubGame.AddBackground()` 用 `RawImage` + `uvRect` 平铺 `rockTexture`，再叠一层 `Strata`。整块背景是**纹理重复**，不是图片。
- 关卡：`Tile_Floor.prefab` 每格一张 `Cave/stone_ground.png`（256×256、254 色、主色 `#878579`），`m_Color` 染成 `#101D26`。

所以「换背景」= 换这张平铺纹理的源图，不是加一层画。任何 16:9 的整图都没有落点。

### 一个比换素材更要紧的发现

`Tile_Floor` 的 tint 是 `#101D26`，而 `stone_ground.png` 主色 `#878579`。两者相乘：

`#878579 × #101D26 ≈ #080F12`，纹理内部明暗差（`#645E52`–`#8E8C81`）被压到 3–7 个色阶，占 255 的 **约 2%**。

也就是说**现在这块石头地面基本是看不见的**，全靠 tint 撑着。换任何更漂亮的地面纹理，乘完还是一块深蓝布。顺序应该是：先把 tint 提到 `#2A3A48` 一档让纹理露出来，再决定要不要换源图。

另一个细节：`Tile_Floor` 尺寸是 98×98，`cell` 是 100 —— **每格之间留了 2px 缝**。换满格地面纹理时这条缝会变成明显网格，要么补成 100，要么当成刻意的分隔线。

## 九、建议的落地顺序

1. **Ninja Adventure**（CC0，免费）先补 **木箱 + 门 + 开关 + UI**，最快看到萌版整体感。
2. **Cozy Fishing 免费版**先试色板，确认贝壳当空螺壳、扇贝当感应格成立，再决定是否买 $3.99。
3. **Sprout Lands UI 免费版**换掉现在那张 `rounded.png`，看圆角粉彩是否合适。
4. 需要水草会动，再上 **Fleuff Underwater Props**。
5. 最后统一描边宽度 + 调色板 + 修 cell 的整数倍缩放。

## 十三、JellyRun（果冻潮池）背景与平台素材

**先定性**：JellyRun 是 2D 横版平台游戏（`JellyRunGame.cs`，20 关、5 处潮心），和前面各节的俯视棋盘是两类需求——这里**正需要横版视差背景**。

**核心结论：项目里已经有一套对口素材，只是闲置。**

`Assets/Resources/ManualArt/underwater-diving-files/` 是 ansimuz 的 **Underwater Diving** 素材包，公有领域（许可原文见 `public-license.txt`："Public domain and free to use on whatever you want, personal or commercial. Credit is not required"），OGA 页标 CC0。目前 `JellyRunTiles.cs` 只加载了 `tiles.png` 一张，另外三张一直没用：

- `PNG/environment/background.png` 288×256，6 色，深蓝底 + 亮蓝岩壁裂缝，可横向平铺做最远层
- `PNG/environment/midground.png` 960×512，6 色，深青绿岩洞结构，做中景层
- `PNG/environment/props.png` 1024×496，19 色，透明底，石拱门 / 图腾柱 / 海草 / 珊瑚 / 藤蔓，可当关卡装饰
- `PNG/environment/tiles.png` 480×656，已在用，切成 `tiles_0..21` 做平台表面

来源：https://ansimuz.itch.io/underwater-diving （免费）｜镜像 https://opengameart.org/content/underwater-diving-pack

**为什么用户觉得不适配（已看图确认，判断成立）**
1. 主角是暖橙 8 色粗描边大眼小鱼（48×48 萌系），ansimuz 的 tiles 是 16-bit 写实暗绿苔石、密集点状纹理，两种风格同屏冲突。
2. JellyRun 的实际色调由 `JellyRunGraphic.cs` 决定：青蓝半透明渐变（`#6CF5DC`/`#8ADCFF` 一组），`JellyRunData.cs` 的 accent 也是青蓝橙。ansimuz 那套偏深绿土色、props 里是玛雅石拱门/图腾柱，色调和叙事都不合。
3. 关卡叫"果冻潮池""潮心"，是梦幻水世界；源包是潜水员躲水雷的洞窟。

**如果要换素材：按"萌系 / 青蓝 / 果冻感"筛，不是"暗黑写实洞穴"**

上一轮推荐的 Deep Cave / Shroom Cave / Cave Platformer 都是暗色写实风，同样不搭，已排除。下面几条是 2026-11-27 搜索摘要，**当次 itch 页面抓取失败，未看图、未核对价格**，仅作候选，下载前必须自己开预览确认：

**关键提醒：换背景/平台素材解决不了"不适配"的根因。** 不适配是**风格差异**：小鱼是 48×48、8 色、粗描边的萌系；任何 16×16 写实 tileset（ansimuz 或上面那些）放进去都会风格不一致。两条路选一条：
