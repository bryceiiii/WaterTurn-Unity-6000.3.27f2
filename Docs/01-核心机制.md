# WaterTurn 核心机制设计稿

> 版本：v0.1（规则闭环版）  
> 状态：待原型验证  
> 说明：本稿为设计草稿，正式落地前需经团队评审。

---

## 1. 一句话定位

**操控一块果冻在四向重力的房间里搬动一条鱼，靠弹射在两块果冻之间跳。**

品类：回合制空间解谜。不是平台跳跃，不是动作游戏。

---

## 2. 核心规则

### 2.1 果冻

- 刚性块，有固定体积，没有流体性质（想象成果冻，不是水）
- 受重力影响，房间旋转后整体掉落到新的底部
- 只能被旋转搬运，鱼推不动
- 有明确边界，玩家能一眼看出安全区范围
- 过不了比它窄的通道

### 2.2 鱼

- **只能在果冻内部游动**，这是唯一可控状态
- 离开果冻后完全失控，没有任何方向微调
- 接触果冻即陷入，立刻恢复控制
- 活动空间 = 果冻体积（果冻越大，瞄准自由度越高）

### 2.3 旋转

- 三种角度：90° / 180° / 270°（加初始朝向共四种重力方向）
- 一次旋转 = 整个房间重排：果冻掉落、重力改向、鱼的状态变化
- **鱼腾空时不可旋转**（已定）
- 旋转本身无风险，风险来自"它把果冻挪到了别处"

### 2.4 弹射

- 唯一的跨果冻位移手段
- 8 向吸附（上下左右 + 四斜向），不做自由角度
- 力度固定，不做蓄力
- 弹射前显示轨迹预览，轨迹随重力方向变化
- 弹出即承诺，不可取消

### 2.5 死亡判定

- 判定时点：鱼撞到**第一个实体表面**的瞬间
- 该表面是果冻 → 存活，陷入，恢复控制
- 该表面不是果冻（地板 / 墙 / 天花板 / 障碍）→ 死亡
- **空中飞行途中不判定**，可以飞越干区上方
- 死亡后立即回到本关起点（目标 0.5 秒内）

> 四向重力下，「地面」可能是墙壁或天花板，判定逻辑统一处理，不单独区分方向。

## 3. 回合结构

一回合 = 观察 → 决策 → 执行 → 结算

| 阶段 | 玩家在做什么 | 系统反馈 |
|---|---|---|
| 观察 | 在果冻里游动，看轨迹预览 | 轨迹虚线随重力方向实时变化 |
| 决策 | 转房间 / 弹射 | 果冻落点以半透明轮廓预示 |
| 执行 | 按键 | 0.3s 旋转动画 / 0.5s 弹射飞行 |
| 结算 | 活着或重来 | 0.1s 内出结果，不拖沓 |

## 4. 果冻规格

| 形态 | 尺寸 | 用途 | 限制 |
|---|---|---|---|
| 安全屋 | 3×3 | 带鱼大范围移动，旋转全程安全 | 过不了窄缝 |
| 垫子 | 5×1 | 空中弹射中继台，做二段跳 | 只给 1 格高度瞄准空间 |
| 塞子 | 1×1 | 填补缺口并固化，造出新地面 | 一次消耗，不可复用 |

**塞子规则**：填入缺口后固化，边角变直角、颜色加深，成为地形的一部分，不可再被旋转带走。这构成资源互斥——同一块果冻不能既当安全屋又当塞子。

## 5. 前三关（教学）

| 关 | 配置 | 教学目标 | 预期死法 |
|---|---|---|---|
| 1 | 1 块 3×3 果冻，1 个出口 | 只教旋转，怎么转都死不了 | 无 |
| 2 | 2 块果冻，中间干区 | 只教弹射，下方必留果冻接应 | 无 |
| 3 | 1 块悬空果冻 | 只教果冻会掉，整间房会重排 | 无 |

三关过关后再引入「弹射 + 旋转」的组合，认知负担刚好。

---

## 6. 设计红线

1. **每关必须能回答「果冻为什么过不去」** —— 否则玩家会一直缩在果冻里挪，弹射永远用不上
2. **最安全的解法不能是唯一解法** —— 逐关检查是否存在"带果冻慢慢挪"的万能解
3. **前三关必须死不了** —— 玩家在最开始被吓住，后面会一直保守，再也教不会弹射
4. **1×1 果冻别拿来装鱼** —— 鱼进去没有瞄准空间，只能盲弹，容易变成"卡死等旋转"
5. **两个物体同时掉落必须给落点预示** —— 果冻给预示，鱼不给，紧张感留给鱼

## 7. 待验证参数（原型阶段调）

| 参数 | 起始值 | 作用 |
|---|---|---|
| 弹射飞行时长 | 0.5s | 太长会闷（空中无操作），太短看不清结果 |
| 旋转动画时长 | 0.3s | 太慢节奏拖，太快玩家看不清果冻去向 |
| 果冻占房间比例 | 1/3 | 这是唯一的难度旋钮，最难关压到 1/8 |
| 死亡重生耗时 | 0.5s | 解谜必须允许免费试错 |
| 落点预示强度 | 半透明轮廓 | 太显眼会削弱推理，太淡会看不清 |

## 8. 已验证排除的方案

| 方案 | 排除原因 |
|---|---|
| 水有流体性质 | 水位无形，玩家算不准，解谜不公平 |
| 鱼能被水抛弃致死 | 旋转会变成威胁动作，玩家会回避核心机制 |
| 鱼站在果冻上行走 | 鱼离开果冻就不能动，站立状态无操控意义 |
| 弹射自由角度 | 差几度就死，变成手感考验而非思路考验 |
| 空中允许旋转 | 算错可挽回，削弱"弹射前想清楚"的核心张力 |
| 蓄力弹射 | 同上，会把解谜导向手感 |
