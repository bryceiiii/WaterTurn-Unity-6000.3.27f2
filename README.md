# 借水过河 · WaterTurn

Unity 6 **6000.3.27f2**（22188f149405），Universal 2D URP，Windows 桌面原型。源代码、地图和渲染设置都在这个工程里。

用 Unity Hub 将本目录添加为项目，使用指定版本打开 `Assets/Scenes/WaterTurnHub.unity`（Build Settings 第 0 个场景），然后进入 Play 模式。序章洞穴里方向键或 WASD 游动，E 或空格与海草共鸣；进入关卡后，空格或 E 顺时针转 90°，Q 逆时针转 90°，Z 撤销，R 重来，H 提示，Esc 或“回洞穴”按钮回到序章。过关依次解锁，有本地进度；首局从序章的潮汐珍珠开始。

## 核心规则

- 鱼只能进入相邻水格。房间可以顺时针或逆时针旋转；旋转后，墙和机关保留在地图上，水朝屏幕下方落，鱼随所在的水格移动。
- 木箱随房间旋转，在格子上的位置保持固定。鱼可以从水里推开木箱，借箱子改变落水路线。
- 栅栏让水通过，但鱼碰到栅栏会死：会让鱼撞上栅栏的一步不再只是提示，而是直接触发死亡动画。
- 水落定在青色感应格上会解锁闸门。闸门打开后水会在同一步继续下落。
- **闸门和栅栏都致命**：鱼站进闸门格（自己游进去，或被旋转带着落进去），或者某一步会把鱼拖进栅栏，都会立刻死亡——播死亡动画、屏幕碎裂，然后从黑场重开本关。撞栅栏不再只是“换一格水再试”的提示。
- **旋转永远允许**，哪怕这一转会先把鱼送进闸门或栅栏；死的是鱼，不是这一步操作。
- 提示求解器会绕开闸门格（栅栏本来就走不过去），所以 H 给出的路线不会把鱼送死；要自己赌一把时，游戏不会阻止。
- 珍珠要由鱼亲自收集。撤销会同时恢复朝向、水、箱子、闸门和珍珠状态。

## 序章 · 潮汐洞穴

`Assets/Scenes/WaterTurnHub.unity` 是新的初始场景，也是一个很短的探索关：

- 一座被海水淹没的旧矿道：五个石室由蜿蜒的两格宽水渠相连，周围还有干涸的侧道、岩洞和碎石。小鱼只能在水里游，干燥的洞底只是布景。
- 五座石室每座四面各有一个潮心，共 **20 个关卡入口（01–20）**；潮心按通关进度逐个点亮，不再只有三个入口。右上角的“关卡 x / 20”显示当前可达数量。
- 潮汐珍珠沉在东南石室。游过去碰到它，西北石室的“第一关”潮心才会苏醒。
- 镜头会平滑跟随小鱼：默认 1.2 倍，可用鼠标滚轮或 `+` / `-` 在 1.06–2.2 倍之间缩放；靠近地图边缘时自动停住，不会露出地图外的空白。
- 游到发光海草旁按 E / 空格，海草会把小鱼送进对应的关卡。第一关需要珍珠唤醒；之后按 01→20 的顺序逐个解锁。
- 第一关通关后，东北、西南两扇石门同时打开，露出第 5–8 关与第 13–16 关的潮心；隐藏关“静水回声”也在这时开启。它是第 21 张地图，不在 20 关的编号列表里，只能从洞穴进入。
- 关卡结算后按 Esc 或点“回洞穴”回到序章；小鱼会从**刚才那一关的潮心旁边**游出来，而不是回到中央起点。进度、珍珠和石门状态都存在 PlayerPrefs 里。

## 小鱼美术

洞穴里自由游动的小鱼和每关棋盘上的鱼棋子，现在共用同一套像素素材（48×48，四方向游动 + 四方向跳跃）：

- `Assets/Resources/Art/Fish/swim_{right,left,up,down}_0..3.png` · 四方向游动，每帧 110 ms。洞穴里按游动方向切换朝向并循环播放；关卡里播放右向循环。
- `Assets/Resources/Art/Fish/Jump/jump_{right,left,up,down}_0..3.png` · 跳跃四段（100 / 70 / 130 / 90 ms），已导入备用，暂时没有接进玩法。
- `Assets/Resources/Art/Fish/death_0..5.png` · 死亡六帧（90 / 120 / 150 / 180 / 220 / 320 ms）：受击 → 抽搐 → 翻肚 → 漂浮 → 下沉 → 没入暗处，只画了右向，左向由 Image 水平翻转。
- 导入规则沿用 `Assets/Editor/PixelArtImport.cs`：Point 过滤、无压缩、16 PPU、Center 轴心、48×48 不裁边，因此每帧重心一致，切换方向不会跳。
- 换素材时保持 48×48 画布、文件名不变即可，`Assets/WaterTurn/FishArt.cs` 会按名字加载。

## 关卡水面

- 关卡里的水格不再给每一格套一张 153px 的方形水花贴图；连续水体现在按四方向邻接自动拼接。
- 水块的外露边缘用 alpha 渐变柔化，外角自然收圆；内部相邻水格之间没有接缝或方框。
- 水格仍是整格碰撞判定，鱼可以游到视觉边缘附近；外圈只保留很淡的水光。
- 水流帧动画保留，但不再有每格重复、互相叠压的白色水花。

## 转场与演出

所有场景切换和结算都由 `Assets/WaterTurn/WaterFx.cs` 统一负责：一块 `DontDestroyOnLoad` 的全屏 Canvas（sortingOrder 5000），不依赖预制体、后处理或额外美术。

- **进入关卡 / 回到洞穴**：硬边圆形光圈从四周收到圆心（0.6 s，圆心锚在屏幕上部 1/3）→ 黑场停 0.3 s → 新场景从同一点由小圆放大铺满（EaseOut，0.6 s）。没有白场、滑动或叠化；光圈是用 `IrisGraphic` 现场构网格画的，不是缩放贴图，所以边缘始终是硬的。
- **通关结算**：背景压暗并轻度失焦（截一张 1/5 分辨率的画面再用双线性放大，等于廉价模糊）→ 青绿色云朵边框卡片从中心带轻微回弹放大（0.3 s）→ 三条成绩逐行淡入。卡片上的按钮或 Enter / 空格 / Esc / 点击都能继续，15 s 无操作自动回洞穴。
- **死亡**：蓝白冷闪 + 白色冲击圆环，同时小鱼播死亡帧；随后 45° 菱形网格从中心向外逐格打洞变黑（每格带一点稳定抖动，所以破裂边缘不是完美圆形），角色和场景碎成像素小方块向四周上方飘散渐隐；黑场后光圈重开、本关重来。
- 洞穴里原本的黑色淡入会让位给这套光圈：`HubGame` 检测到 `WaterFx.PendingIrisOpen` 时不再自己从黑幕淡入。
- 调试用 `WaterFx.DebugSpeed`（1 = 原速，调小可逐帧看转场）；它只影响演出，不影响玩法。

## 连锁关卡

| 01 先游，再转 | 鱼只能在水里移动。先游到上方的水格，再转动房间。 | 2 |
| 02 同水异路 | 相邻的水格转过去以后，可能被墙分成不同水道。 | 2 |
| 03 换一股水 | 水落定之后，还有机会换乘另一块水。 | 4 |
| 04 沿岸折返 | 不要只看出口离鱼有多远，先看下一次会落到哪条槽。 | 5 |
| 05 两排蓄水 | 一排水负责接鱼，另一排水负责把它送过墙角。 | 5 |
| 06 挪开木箱 | 木箱在地图上固定。游进带箱子的水格，就能把它推走一格。 | 5 |
| 07 把箱子留下 | 让箱子留在你想挡住的水道上，再改变重力。 | 3 |
| 08 先推再回头 | 推过木箱之后，留意鱼有没有换一条水路的机会。 | 5 |
| 09 一格之差 | 改变箱子的位置，会改变下一次转动时水停在哪一格。 | 4 |
| 10 水能过，鱼不能 | 栅栏只放水过去。鱼撞上栅栏会死，别把它往栅栏里带。 | 5 |
| 11 隔栅搭船 | 先让无人乘坐的水穿过栅栏，再安排鱼的路线。 | 5 |
| 12 只差一格 | 在下一次转动前换水，有时能避开看起来必经的栅栏。 | 4 |
| 13 双向回流 | 同一个栅栏会在不同朝向下拦住不同的水路。 | 3 |
| 14 水压开门 | 当水落定在青色感应格上，闸门会永久打开。 | 4 |
| 15 让水先走 | 感应格只需要水，不需要鱼亲自过去。 | 7 |
| 16 门开以后 | 水触发闸门后会继续流。比较开门前与开门后的落点。 | 7 |
| 17 水位交接 | 倒推出口所在的水路，再找哪一股水能替你先开门。 | 5 |

| 19 折返水道 | 拿到珍珠后还得回来，先想好木箱该停在什么地方。 | 11 |
| 20 回潮室 | 先分配水块的任务，再决定鱼搭哪一格。集齐珍珠才能交付。 | 8 |
| EX 静水回声 | 隐藏关。先推箱借道，再让水替你按下感应格；石门打开后回声会带你回到出口。 | 10 |

加入逆时针后，求解器会同时搜索两个旋转方向；关卡数据本身尚未改动，因此部分旧关卡的最短解明显变短（例如 02 从 6 步变 2 步）。后续重做关卡时再按新机制重新收紧步数。

章节起点 01、06、10、14、18 分别引入换水、木箱、栅栏、水压闸门、珍珠。每个章节的第一关先让玩家辨认新规则，接着用分流、借另一股水完成任务、回到先前水道等组合推进。20 关要求让箱子、鱼、先到感应格的水各履其职。第 21 关是洞穴隐藏关，不参与编号解锁。

## 手动调整大厅

大厅的入口和镜头现在可以在 Unity 里直接调，不必改代码：

- **拖动关卡入口**：打开 `WaterTurnHub`，在 Hierarchy 里展开 `TidalHollow/Level Entrances`。`Portal 01` … `Portal 20`、`Hidden Portal` 都是可拖动的空物体，Scene 视图里会显示编号、关卡名和潮心颜色。移动后重新 Play，潮心会出现在新位置。
- **改入口信息**：选中锚点，在 Inspector 的 `HubPortalAnchor` 上改 `level`、`title`、`subtitle`、`activeColor`、`haloColor`、`compact`；`title/subtitle` 留空会自动读取关卡编号和 `Campaign` 关名。
- **重建设置**：菜单 `WaterTurn/Hub/创建关卡入口锚点`、`重置入口锚点位置`、`删除关卡入口锚点`。入口全部删掉时，`HubGame` 会退回代码里的默认布局。
- **镜头参数**：选中 `TidalHollow` 的 `HubGame`，在 Inspector 的 `Camera Authoring` 里调 `defaultZoom`、`minZoom`、`maxZoom`、`cameraBiasY`、`followSpeed`、`zoomSpeed`、`viewSize`。
- **场景辅助线**：`HubGame` 和每个 `HubPortalAnchor` 都带 Gizmos；Scene 视图会画出 1260×756 的地图范围和粗网格，方便把锚点对到石室/水渠上。
- 入口锚点是在 Play 开始时读取的，所以改完位置后要重新进入 Play；镜头参数在 Play 中改 `cameraBiasY`/`followSpeed` 等会立即生效。

当前岩石、水渠和装饰仍是程序化生成；如果要把它们也变成可在 Scene 里逐个拖动的美术对象，可以在此基础上继续做“烘焙”。

## 果冻潮池 · JellyRun 横版 demo

这是一个与“潮汐洞穴 / 二十关解谜”并行的独立横版场景，玩法与美术来自 `Docs/waterturn-fish-run.html`，但把原来的“收集 20 颗珍珠”改成了 **5 处潮心 × 每处连续 4 关**。

- 打开 `Assets/Scenes/JellyRun.unity` 直接 Play；也可以在潮汐洞穴右下角点“果冻潮池 · 5 处关卡入口 ▶”或按 `J` 进入。
- **A / D、← / →** 水里游动、空中微调；**W / S、↑ / ↓** 上浮 / 下潜蓄力；**Space** 跃出果冻，空中再按一次是二段跳；**E** 站在潮心石台上进入章节；**R** 回最近水池；**H** 帮助；**M** 静音；**Esc** 回潮汐洞穴。
- 五处潮心分别对应 **潮池 01–04 / 断桥 05–08 / 水闸 09–12 / 尖刺走廊 13–16 / 终章 17–20**。站上石台、靠近潮心按 `E` 才会进入；跳跃、下落擦过不会触发。进入后连打 4 关：通关结算后自动进入下一关，第 4 关后回到同一处潮心。中途 `Esc` 回本场景，再进入从本章第一个未通关的关卡继续。
- 20 个关卡位全部通过后，终点漩涡变金色并开启；结算显示用时、失误、20/20、5/5。JellyRun 的完成度独立保存在 `WaterTurn.JellyRun.Cleared.v1`，不依赖旧存档的 `LevelsCleared`。
- 入口石台位置：潮池 (600,580)、断桥 (2575,684)、水闸 (3905,644)、尖刺走廊 (5055,684)、终章 (7265,174)；编辑器菜单 `WaterTurn/JellyRun/校验入口布局` 会检查 5 处入口、20 关映射和最小间距。
- 场景美术（洞窟、岩体、果冻、尖刺、锯片、闸门、机关、潮心、终点、HUD）全部在运行时按 HTML 的配色/形状生成，不新增图片；小鱼使用工程已有的 `FishArt` 48×48 像素帧（Swim / Jump / Death），与 Hub、关卡里的鱼是同一套素材。
- 与 `runScence` 分支里旧的“20 段连续走廊”原型无关，不合并、不覆盖。
