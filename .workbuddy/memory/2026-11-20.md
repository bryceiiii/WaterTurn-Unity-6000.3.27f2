## 用 Super Retro World 水动画素材替换游戏内水/墙/箱子

素材来源：`Art/Super_retro_world_water_animation/`（`spritesheet_16x16_5frames.png` 80x16 = 5 帧 16x16 水动画；`SuperRetro_Banner_Tileset.png` 256x256 图集）。

产出（切开后的独立精灵，放在 `Assets/Resources/Art/Water/`，原始两张 PNG 备份在同目录 `Source/`）：

- `water_0..4.png` 16x16 —— 5 帧水波纹，运行时 7fps 循环
- `rock.png` 48x48 —— 图集 (0,64) 石灰岩方块，用作墙
- `wood.png` 29x32 —— 图集 (57,192)，木板，用作箱子（右边缘原带灰色岩石，已裁掉）
- 曾切过 `grass.png` / `pool.png`，未使用，已删

`Assets/Editor/PixelArtImport.cs`：AssetPostprocessor，把 `Assets/Resources/Art/` 下的贴图强制成
Point 过滤 + 不压缩 + 无 mipmap + PPU16 + Sprite(Single) + FullRect。注意：**首次导入时脚本还没编译，
后处理器不生效**，新素材第一次进来需手动 `ImportAsset(ForceUpdate)` 再触发一次。

`WaterGame.cs` 改动：

- `LoadArt()` 用 `Resources.Load<Sprite>("Art/Water/xxx")` 载入 5 帧 + rock + wood；缺帧时回退纯色水格
- `AnimateWater()` 在 `Update` 最前面跑，按 `Time.unscaledTime*7` 切帧（写在键盘判断之前，否则会漏帧）
- 水格：`Cell(..., cell + 2, Color.white, waterFrames[0])`，比格宽 2px 让相邻水连成一片
- 墙：# 先铺 `cell+1` 深色底（32,42,52）再叠 `cell` 岩石精灵（tint 188,202,232），否则岩石不规则边缘会漏出网格缝
- 箱子：wood 精灵 `cell*.84`，木头素材到位时不再画原来的琥珀色斜撑
- 出口：金棕圆角块 `cell*.78` (196,148,82) + 中心深色洞 `cell*.40`（(26,34,44)）—— 文案写「金色出口」，所以不能用草地切片

## 工具链坑：UnityMCP 连的是别的工程

MCPForUnity 只注册了 `D:/UnityProjects/JumpTurn`，而本工程编辑器（端口 7803）只装了 `com.unity.pipeline`。
两者同时在跑时，MCP 的 `execute_code` 全打在 JumpTurn 上（表现出来是「文件不存在 / Assets/Resources 为空」）。
正确通道：`unity command eval --caller plugin --skill unity-cli --project-path <本工程> 'return ...;'`，
截图用 `unity command "capture game_view" --output-path ...`。

另外两个坑：

- 编辑器窗口失焦且 `Application.runInBackground=false` 时播放循环会停（`Time.frameCount` 卡在 1），
  截图全是旧帧。修：播放中 `Application.runInBackground = true;`
- 播放模式下改脚本，退出播放后要确认 `Assembly-CSharp.dll` 时间戳新于 .cs，否则新代码没进构建，
  会出现「尺寸变了但颜色没变」这类半新半旧的假象

## 水面泡沫边缘（Art/Water/Foam/Foam.png）

素材是 1536x192 = **8 帧 192x192**，每帧真正内容只有 86x86 居中（bbox 53..138）：
一个薄荷色 (198,240,219) 方块 + 方块内侧一圈青色描边 + 方块外侧散落的白气泡。
也就是「带气泡边的水块」，不是可直接用的四条边贴图。

处理（`Temp/foam.py`）：每帧裁 88x88 @(52,52) → 从中心按颜色 BFS 出内部填充 →
保留距泡沫带 7px 以内的填充、更深的内部挖成透明，得到中心透明的泡沫环。输出 `Assets/Resources/Art/Water/foam_0..7.png`。

用法（关键技巧，免去做 9 宫格自动拼接）：
**把泡沫环当每个水格的子层，画在水面之下**。`ImageOn` 顺序在 tile 之后、water 之前，
所以泡沫盖住地板、被所有水面盖住 → 只露出水体轮廓外的那一圈，相邻水格之间的内部接缝自动被盖掉，
凹角也能正常贴合。水面越大越不会出现内部泡沫线。

- 尺寸 `(cell + 2) * 1.5f`：放大到 1.5 倍才能让可见边厚一点（原图泡沫带只占 9%）
- 位置在 `Paint()` 里跟着 `waters[i]` 同步，旋转/移动不会脱节
- 动画 4fps（8 帧），比水面的 7fps 慢，避免边缘闪太快

坑：素材的薄荷填充如果直接缩放贴边，会因为泡沫外缘起伏只露出零散小凸起（看着像毛刺）。
必须把泡沫整体放大让内圈埋进水面里，才有连续泡沫带。
