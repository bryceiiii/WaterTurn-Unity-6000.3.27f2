## 22:25 修复 MissingReferenceException（JellyRunArt 静态缓存跨播放会话）
- 现象：第二次 Play 时 `JellyRunGame.BuildBackground` 在 `JellyRunArt.Cave(0).texture` 抛
  `MissingReferenceException: The object of type 'UnityEngine.Sprite' has been destroyed`。
- 根因：工程开启 "Enter Play Mode Options"（domain reload 关闭，`m_EnterPlayModeOptionsEnabled=1/Options=1`），
  静态字段跨播放会话保留；退出播放时运行时生成的 Sprite 被销毁，而 `caves[layer] ?? (...)` 用的是 C# `??`
  （真 null 比较，不认 Unity 的伪 null），于是把已销毁对象当有效值返回。属性用的是 `!= null`（Unity 重载）所以没事。
- 修法（Assets/WaterTurn/JellyRunArt.cs）：
  1. 5 个数组 getter 的 `??` 全部改为 `if (x == null) x = Make...`；
  2. 新增 `madeSprites` / `madeTextures` 登记表（在 `SpriteFrom` 里登记，sprite 加 `HideFlags.DontSave`）；
  3. `[RuntimeInitializeOnLoadMethod(SubsystemRegistration)] ResetForPlayMode() => ClearCache()`，
     `ClearCache` 先 Destroy 遗留对象再清空字段，避免跨会话泄漏纹理。
- 验证：MCP 读运行时——365 个 Image 的 sprite 均 tex 有效，CaveFar/CaveNear 1536x900 存活，
  `caves=[0]live [1]live`，Console 0 error；退出再进入播放模式不再抛异常。
- 经验：**任何静态缓存 UnityEngine.Object 的字段，一律用 `!= null` / `== null`，禁止 `??`**；
  且关掉 domain reload 的工程必须提供 `SubsystemRegistration` 级重置入口。
