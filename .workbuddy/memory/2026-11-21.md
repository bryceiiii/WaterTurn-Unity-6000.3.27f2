## WaterTurn 核心机制定型（策划评审）

基于「鱼 + 果冻 + 四向重力房间」的机制组合，完成第一轮设计评审，确定以下规则：

**物理模型**
- 「水」没有流体性质，本质是刚性果冻块（有限体积、形状固定、有明确边界）
- 果冻受重力，房间旋转后整体掉落到新的底部（不是固定贴墙）
- 旋转 = 一次性重排整个房间：果冻、鱼、重力方向同时改变
- 果冻只能靠旋转搬运，鱼推不动

**鱼的三种状态（核心判定）**
- 泡在果冻里：免重力，跟果冻一起掉 → 安全
- 站在果冻上：有支撑不掉落 → 安全
- 单独悬空：受重力，按落地位置判生死 → 危险
- 死亡条件 = 落到干区，而非「离开水」；腾空状态不受伤（可飞跃干区）

**关键设计结论**
- 旋转不再是威胁而是唯一搬运工具，玩家可放心旋转（避免玩家回避核心动词）
- 「果冻是刚性的」→ 过不了窄缝 → 窄缝自动成为强制跳跃的关卡语法，无需额外设计尖刺
- 果冻三种形态：安全屋 3×3（泡着搬家）、垫子 5×1（干区落脚点）、塞子 1×1（填平缺口）
- 独有玩法：「跳出去 → 房间转走 → 靠重力追上果冻」，这是该组合唯一能产生的动作

**默认参数（待用户确认）**
- 鱼腾空时不能旋转房间
- 鱼腾空后不能改方向 / 无二段跳
- 果冻在旋转动画中同步掉落（约 0.3s，非瞬移）
- 只给果冻落点预示，不给鱼预示（紧张感留给鱼）

**前三关教学顺序**
1. 果冻带你走（只教旋转，死不了）
2. 跳过去有东西接（只教跳跃，下方必有果冻）
3. 整间房重排（只教果冻会掉）
4. 之后再引入「跳跃 + 旋转」组合

**已识别风险**
- 两物体同时掉落 → 认知负荷翻倍，需落点预示辅助
- 最安全解法（带着果冻慢慢挪）可能成为唯一解法，必须每关检查「果冻为什么过不去」
- 水块占比是唯一难度旋钮：前期 1/3，最难关 1/8

## 追加：规则闭环 + 设计文档落地

用户进一步澄清并拍板，规则已闭环：

- **鱼只能在果冻里游**，离开果冻完全失控，接触果冻即陷入（"站在果冻上"不是稳定态）
- **死亡判定只在落地瞬间**：鱼撞到的第一个实体表面若是果冻则活，否则死（地板/墙/天花板统一处理）
- 空中飞行途中不判死，可飞越干区上方
- 鱼活动空间 = 果冻体积，果冻尺寸即难度旋钮（3×3 有 9 格瞄准空间，1×1 只能盲弹）
- **已拍板参数**：弹射 8 向吸附、力度固定不蓄力、鱼腾空时不能旋转房间
- 因此游戏定位为**纯回合制空间解谜**（回合 = 旋转 + 弹射），非平台跳跃

**已排除方案**（写入文档备查）：流体水、旋转致死、站立行走、自由角度弹射、空中旋转、蓄力弹射
