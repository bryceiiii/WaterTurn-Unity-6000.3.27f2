## PuzzleForge 两个修正：试玩残影 + 导出场景

- **Bug：试玩旋转后出现两条鱼**。根因不是解算，是渲染：`RowsFromPosition` 直接在 `Level.Tiles`（开局盘面）上叠当前位置，鱼/箱子/水挪走后旧格子的字符还留着。现改为 `ForgeBoard.RowsFrom(level, position)`：先把 `P/B/b/~` 抹成 `.`、拿走珍珠时抹掉 `K`，再按 `position.Water` 铺水（`E/K/o` 保留），再画箱子（水上判 `b`）、最后画鱼。`PuzzleForgeApp.RowsFromPosition` 现在只是转发。
- **导出场景**：新增 `ForgePlayScene.cs`（运行时自建相机/Canvas/盘面/按钮，只吃序列化的 ASCII 行）+ `ForgeSceneExport.cs`（直接产 Unity YAML 场景：模板头取 `Assets/PuzzleForge/scene_header.txt`，实体块自己拼，脚本 GUID 从 `.meta` 读）。因为 Play 模式下 `EditorSceneManager` 建不了场景，才走「写 YAML」这条路。
- 场景结构：`ForgePlay`（挂 ForgePlayScene，字段 packName/theme/names/hints/answers/limits/levels）+ `Main Camera`（编辑模式不至于 No cameras rendering，运行时复用 Camera.main）。多行盘面用 `\n` 转义进双引号标量，Unity 能正确还原。
- 导出入口：底部栏加了「导出场景」（9 个按钮重排 196 宽）；「导出关卡」现在也会连带写场景 + README 第 4 条。
- **踩坑**：Play 模式写出的 `.unity`，Unity 会推迟导入（`AssetDatabase.ImportAsset` 当场无效），停 Play 也不会自动刷新。解法：导出时写 `Assets/PuzzleForge/.pending` 标记，`Assets/PuzzleForge/Editor/ForgeExportWatcher.cs`（`[InitializeOnLoad]` + `EditorApplication.update` 每 0.5s 检查）在非 Play 状态下 `AssetDatabase.Refresh()`。实测停 Play 后场景直接出现在 Project 里。
- 验证：试玩连走 8 步（含 4 次旋转）始终只有 1 个 `P`；导出 WaterHall 3 关场景，打开后 Play，单相机/单 EventSystem，3 关可切，`answers` 步法逐步走通关（6/4 步），控制台零错误。示例导出留在 `Assets/PuzzleForge/Exports/Forge_回廊_Normal_2468/`。

## 导出的关卡场景改成"和正式关卡同一套 Hierarchy/素材"

- 废弃上一版"运行时自建相机/Canvas"的独立场景（删掉 `ForgePlayScene.cs` / `ForgeSceneExport.cs` / `Editor/ForgeExportWatcher.cs` / `scene_header.txt`）。新做法是用正式预制体生成场景，Hierarchy 与 `Level_01..21` 一致：
  `Camera_Level`(prefab) + `EventSystem`(prefab) + `GameRoot`(WaterGame, LevelManager, LevelDefinition) + `GameCanvas`(UI_GameHud prefab) → `Layout/BoardCenter/Room`(LevelBoard) → 地砖/水/泡沫/出口/鱼/箱/闸/栅 prefab 实例。
- 新增 `Assets/PuzzleForge/Editor/ForgeSceneBuilder.cs`：`[InitializeOnLoad]` + `EditorApplication.update` 每 0.5s 看 `Assets/PuzzleForge/.forge-scene-request.json`（点号开头，Unity 不导入），非 Play 时接单建场景。另有 `Tools/PuzzleForge/*` 两个菜单。运行时 `ForgeIO.RequestScenes` 只写请求，所以"点导出 → 退出播放 → 场景自动出现"。
- 关键尺寸（以 cell 为基准，取自正式场景实测）：地砖 墙 cell+1 / 地 cell-2、水 cell+2、泡沫 cell*1.55、鱼 cell*0.68、出口 cell*0.78、箱子 cell*0.84、珍珠 cell*0.32、闸门 cell*0.70、栅栏 cell*0.75；格子坐标 `((col-(W-1)/2)*cell, ((H-1)/2-row)*cell)`，cell = 398/max(W,H) 取 3 位小数。
- **出口不能直接缩 sizeDelta**：`Prop_Exit` 内部有个固定 40px 的洞口，缩到小格子时洞口会盖住整块金框，看起来是个黑格。改成保 `sizeDelta=78` 用 `localScale = cell*0.78/78` 整体缩放，洞口比例才对。
- **`D` 闸门和 `G` 栅栏没有白模**：`WaterGame.BuildMechanismViews` 只给 portal/plate/valve/latch/membrane/spring/S/d 建白模，闸门与栅栏必须由场景摆 `Mechanism_Gate` / `Obstacle_Grate` 预制体（栅栏每格一个，闸门把第一个塞进 `LevelBoard.gate` 让颜色随开关变）。
- **踩坑**：`Application.dataPath` 在 Windows 上带反斜杠，拼出来的路径要 `.Replace('\\','/')`，否则 `AssetDatabase.LoadAssetAtPath` 一律返回 null。另：编辑器窗口没焦点时 Player loop 会停（frame 卡在 15），截图看到的是旧帧；`Application.runInBackground = true` 跑起来后才能截到真实画面。
- 验证：WaterHall 3 关（9×9）场景，Hierarchy 与 Level_01 完全一致（4 个根物体），点 Play 后 HUD/提示/旋转/过关演出都在；三关按导出答案走完（6/4/5 步）全部 `won=True`，过关卡片显示 "01 回廊 01 / 步数 6"。11×11 带阀/闸/压板的关卡（7 步）同样通关。示例：`Assets/PuzzleForge/Exports/Forge_回廊_Normal_2468/Scenes/`。
