# 2026-11-19

## 修复工程编译报错（Unity 6000.3.27f2 / WaterTurn）

根因与处理：

1. `Library/PackageCache/com.unity.collab-proxy@.../MergeTab.cs(55,56)` CS0104
   `'ObjectInfo' 在 Codice.CM.Common.ObjectInfo 与 UnityEditor.ObjectInfo 之间有歧义`
   —— collab-proxy 2.6.0 过旧，与 Unity 6.3 新增的 `UnityEditor.ObjectInfo` 冲突。
   处理：先尝试升到 2.12.4（新版本已加 `using ObjectInfo = Codice.CM.Common.ObjectInfo;`），
   但 UPM 下载 `aborted`，最终直接从 `Packages/manifest.json` 移除 `com.unity.collab-proxy`（项目未使用 UVCS，无 `.plastic`）。

2. `com.unity.inputsystem@.../InputSystemPluginControl.cs(47,25)` CS0117
   `BuildTarget 不包含 ReservedCFE`
   —— inputsystem 1.12.0 使用了 Unity 6.3 已删除的枚举值。
   处理：`1.12.0 → 1.14.0`（1.14.0 改用 `(BuildTarget)49` 强转，可编译）。

3. 隐藏的工程自身错误：`WaterGame.cs` 27 处 `CS0103: 找不到 Campaign`
   —— `Assets/WaterTurn/Campaign.cs.meta` 的 guid 只有 31 位（`094591dce30d4142b34a0cea9bbe525`），
   Unity 判定 meta 非法 → 资源被忽略 → 文件不参与 Assembly-CSharp 编译。
   处理：改写为合法 32 位 guid `1d226140bbbf3e6f1f9b90354a275d82`，touch 文件触发重新导入，
   `Assembly-CSharp.csproj` 恢复包含 Campaign.cs，编译 0 error。

遗留（警告，非错误）：`com.unity.2d.animation@10.1.4` 的
`InfluenceWindowStyle.uss` 报「不支持的选择器格式」（Unity 6.3 的新 USS 解析器更严格）。
不影响运行；如需消除需把 2d.animation 升到 6.3 兼容版本（需联网下载）。

经验：改 `Packages/manifest.json` 后 Unity 解析 + 全量重编译可能耗时 3~5 分钟；
PackageCache 报错一律不要改包内文件（会被还原），应从 manifest 版本入手。
