## 第六关墙体瓦片改造（Puny Dungeon 图集）

**结论：之前把「地板材质」当墙用了。**
- 图集里 `T4_0`（沙色低对比砖）= 地面；`T16_14` / `T16_16` 是它在 sand 分区的复制品，同样是地面。
- 真正的墙族是 cols 0-3 / rows 0-3 的中性灰砖：`T2_3` = 一块完整墙（亮顶面 9px + 底部 7px 暗带），`T0_1` 这类是"竖墙条"（左右都有暗条，铺开会变栅栏，不能大面积平铺）。
- 用户手动在图集里补了 `T0_13`（col0,row13）：**无缝灰砖填充块**，正好补上图集缺的"墙面本体"。

- 其余墙格 → `T0_13`
- 最下面一行左右角 → `T1_2` / `T3_2`
- 统一 color = white（之前 D1D6E0 / A8ABAD 的 tint 全部去掉）
- 地面保持 `T16_14` @ `D9CFBD`
- Wall 与子物体 Rock 两层 Image 都要改；Rock 锚点拉满、offset 0；`RecordPrefabInstancePropertyModifications` + `SaveOpenScenes`
